## ⚡ About

KREST is a powerful terminal-based AI assistant that combines modern language models with real-world tooling.

Designed for developers, cybersecurity specialists, automation engineers and power users.

It helps you:

* Generate code
* Search the web
* Manage files
* Execute commands
* Save sessions
* Maintain workflow context

—all without leaving the terminal.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Pre11yhacker/KREST.git

cd KREST
```

### Install Dependencies

```bash
pip install rich python-dotenv ddgs psutil
```

Optional:

```bash
pip install duckduckgo-search
```

### Run

```bash
python KREST.py
```

## 🔑 OpenRouter API Key

On first launch KREST will request an OpenRouter API key.

Get one here:

https://openrouter.ai/keys

## 🛠 Commands

| Command      | Description          |
| ------------ | -------------------- |
| `/help`      | Show help            |
| `/clear`     | Clear conversation   |
| `/reload`    | Reload system prompt |
| `/context`   | Context statistics   |
| `/sys`       | System information   |
| `/stats`     | Resource usage       |
| `/model`     | Current model        |
| `/models`    | Available models     |
| `/token`     | Update API key       |
| `/deletekey` | Delete API key       |
| `/memory`    | Recent sessions      |
| `/sessions`  | All sessions         |
| `/save`      | Save session         |
| `/load`      | Load session         |
| `/export`    | Export conversation  |
| `/input`     | Read file            |
| `/exit`      | Exit KREST           |

## 🔍 Special Operations

### Search

```text
[SEARCH:python asyncio tutorial]
```

### Read File

```text
[READ:main.py]
```

### Write File

```text
[WRITE:app.py::print("hello")]
```

### Run Command

```text
[RUN:python app.py]
```
